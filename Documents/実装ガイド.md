# 実装ガイド（仕様書との対応）

## 仕様書で未定義・矛盾していた点の決定事項

| 項目 | 決定 |
|---|---|
| 敵AIの名称 | シート3に合わせ `BP_MyCharacter` / `BT_MyCharacter` / `BB_MyCharacter` に統一 |
| 視野角90° | UEの設定値（PeripheralVisionAngle）を90。視界3000cm・見失い3500cm |
| 施錠扉 | A = Key001、B = Key002、最終マスター扉 = Key001〜003すべて |
| リトライ | 位置・鍵・扉をセーブ時点に戻す。プレイ時間と死亡回数は引き継ぐ |
| ダッシュ | Shift長押し |
| 挑戦要素 | 警告UI・BGM/SE・ポーズ画面（聴覚検知は対象外） |

仕様書に数値がないもの（HP100、ダメージ床20、敵の攻撃25、巡回速度170、追跡速度480など）は、各BPの変数で変更できます。

## 機能一覧

| ID | 機能 | 実装場所 |
|---|---|---|
| SYS-01 | 移動・視点・ジャンプ・ダッシュ | `BP_Player`、`IMC_MyDefault`、`IA_*` |
| SYS-02 | HP・ダメージ・死亡 | `BP_Player`（AnyDamage → `OnCharacterHpChanged` / `OnPlayerDead`）。HUDとGameModeはディスパッチャーを受け取るだけ |
| SYS-03 | 鍵の収集 | `BP_Key` ＋ `DT_KeyStatus`（表示名・色）＋ `ItemNameList` |
| SYS-04 | 扉・スイッチ・レバー | `BP_GimmickBase` を親に `BP_Door` / `BP_SwitchButton` / `BP_Lever`。連動は `BPI_Gimmick`、操作は `BPI_Interact` |
| SYS-05 | 移動床 | `BP_MovingBox`（InterpToMovement、PingPong、`SetEventFinished` で復元） |
| SYS-06 | AI基盤 | `BP_MyAiController` BeginPlay → Use Blackboard → Run Behavior Tree、NavMeshBoundsVolume |
| SYS-07 | 巡回 | `BP_MyCharacter.GetNextPatrolPoint`、`BTT_GetNextPatrolPoint`、Cooldown |
| SYS-08 | 発見・追跡 | AIPerception（Sight）→ `bDiscovered` / `TargetActor`、`BTD_CheckUndiscovered` |
| SYS-09 | 見失い | 最後に見た場所を調べてから（`bSearching`）巡回へ復帰 |
| SYS-10 | セーブポイント | `BP_SavePoint`、`N_SaveLight`、`UW_ScreenEffect`（Flash）。`BPI_Player` 経由でCastなし |
| SYS-11 | 永続セーブ | `BP_MyGameInstance`（Export / Import / Delete）→ `BP_MySaveGame` スロット `MySaveGame` |
| SYS-12 | タイトル・クリア・リセット | `WBP_Title` / `WBP_GameOver` / `WBP_Clear` / `WBP_Pause`、Rキー長押し |

## ビヘイビアツリー

```
Root Selector
├ Undiscovered（BTD_CheckUndiscovered / Aborts Both）
│ ├ Search（bSearching が Set）   MoveTo 最後に見た場所 → Wait 2.5秒 → BTT_EndSearch
│ └ Patrol（Cooldown 1.5秒）      BTT_GetNextPatrolPoint → MoveTo PatrolPoint
└ Chase                           MoveTo TargetActor
```

仕様書のキー（TargetActor / PatrolPoint / bDiscovered）に加え、見失い用に `bSearching` と `LastKnownLocation` を追加しています。

## メニューのキーボード操作

`WBP_MenuBase` を親クラスとし、タイトル・ポーズ・ゲームオーバー・クリアの4画面が継承しています。

- 各画面は `GetMenuButtons` をオーバーライドしてボタンを登録するだけ
- `OnPreviewKeyDown` で上下移動（無効なボタンは飛ばし、端で回り込む）。決定はフォーカス中のボタンが処理
- `OnFocusReceived` で、背景をクリックしても選択中のボタンにフォーカスを戻す
- マウスを乗せるとその項目が選択状態になる
- タイトルの初期選択は、セーブがあれば「つづきから」

## セーブの流れ

```
BP_SavePoint --(BPI_Player.PlayerSaveData)--> BP_Player --> BP_MyGameInstance.ExportSaveData --> BP_MySaveGame（スロット）
起動時 GameInstance Init → ImportSaveData
レベル開始時 BP_Player BeginPlay → DelayUntilNextTick → PlayerLoadData（所持品 → 位置・向き）
各ギミック BeginPlay → GetEventStatus が true なら SetEventFinished（演出なしで完了状態へ）
```

## 素材
- キャラクター：UE標準マネキン（使用分のみ）
- 壁・床・天井・扉・小物：Fab無料素材2種（`Content/Fab/`、4K/2Kテクスチャを1024pxに縮小、未使用分は削除）
- 壁や床のパネルは `BP_TileField`（Construction Script ＋ Instanced Static Mesh）で配置。当たり判定は非表示の箱が担当
- BGM / SE：プログラムで合成した自作音源
- マテリアル・Niagara・鍵メッシュ：自作
